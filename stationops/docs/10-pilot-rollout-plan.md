# 10. Two-week pilot rollout plan

One station, opening shift only. Day 0 is go-live. Before day 0, docs 1–4 and 7 are complete.

## Before go-live (the week before)

| When | Activity | Who |
| --- | --- | --- |
| Day −7 | Discovery meeting; watch one opening (doc 1). Count the last 2 weeks of paper checklists for a baseline, if they exist | Lead + manager |
| Day −6 | Scope signed (doc 2). Draft checklist wording with the manager (doc 3) | Lead + manager |
| Day −5 | Deploy; create the restaurant and accounts; enter the approved checklist; enter the baseline period | Lead |
| Day −4 | UAT on the restaurant's own devices at the station (doc 4) | Lead + manager |
| Day −3 | Fix anything critical; re-test | Lead |
| Day −2 | Manager training (doc 6), 20 minutes | Lead → managers |
| Day −1 | Staff briefing at shift change (10 minutes); post the staff guide; go-live approval (doc 7) | Manager + lead |

## Week 1 — adopt

| Day | Focus |
| --- | --- |
| 0 | Lead on site (or on call) for the first opening. Help each employee once, then step back |
| 1–2 | Manager checks the dashboard every morning at the agreed time and resolves issues the same day |
| 3 | Quick check-in with the manager: what's confusing? Any tasks worded badly? Edit tasks only if the manager agrees, and note it in **What changed?** |
| 4–6 | No changes unless something is critical. Log project issues (doc 8) |
| 7 | Weekly review: completion rate so far, issues log, staff feedback |

## Week 2 — measure

| Day | Focus |
| --- | --- |
| 8–12 | Steady state. No checklist changes unless something is critical, so week 2 measures a stable process |
| 13 | Add the **Pilot** period on the Pilot metric page with the expected count from the actual schedule. Export the CSVs |
| 14 | Results review and handoff (doc 9): numbers as measured, feedback, decision |

## Watch-outs

- **Low completion in week 1 is normal.** Look at *why* (not started vs. exceptions vs. never submitted) before judging.
- **Count expected checklists from the real schedule.** Closed days are not expected; a missed opening is.
- **Changing the checklist mid-pilot** makes week 1 and week 2 less comparable. Record any change.
- **Don't backfill missed checklists after the fact.** A missing record should stay missing.
